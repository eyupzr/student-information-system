# Student Information System

## Project Description
A C++ command-line application for managing
student information using PostgreSQL and Docker.

## Features
- Add student
- List students
- Update student
- Delete student

## Technologies
- C++
- PostgreSQL
- Docker
- Bash
- Git and GitHub
